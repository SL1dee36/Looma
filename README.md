# Looma

Современная лёгкая платформа для совместного просмотра фильмов и YouTube.

## Стек
- **Backend**: TypeScript, Node.js, Fastify, WebSocket, SQLite (Drizzle ORM)
- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Стилистика**: Deep Cinema Minimal

## Разработка
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```
